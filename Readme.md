# LiveSet — Work in Progress 

I'm currently building **LiveSet**, a Python app for organizing songs, playlists, and lyrics.

Right now, it has basic CRUD functionality using SQLite, and I'm working on adding more features. I also used Claude Code to help me build the initial frontend, which I'm running locally.

## Technologies Used
- Python
- FastAPI
- SQLite
- SQL
- HTML
- CSS
- JavaScript

## Purpose

I'm building this project to improve my Python, backend development, and SQL skills. As a musician, I also have a pretty good idea of what I'd want to see in an app like this.

## Future Improvements

- **DJ Mode:** Suggest a song order within a playlist based on BPM (tempo). For example, songs with similar BPMs, within a range of around ±5 BPM, could be easier to mix together for mashups. Of course that would be a suggestion because it also depends on genre, decade and style of each song.
- **Lyrics:** Add the ability to store lyrics for each song.
- **Musical Key:** Add the musical key of each song to help with song selection and mixing.
- More features as the project develops.
